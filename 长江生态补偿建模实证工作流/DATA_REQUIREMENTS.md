# 第一轮数据交接清单

不要求一次性全部提供。优先交接带星号的项目。

## 一、补偿资金流

- [ ] ★ 每笔补偿的付款省、收款省、年份、金额；
- [ ] ★ 对应协议、财政文件或公开链接；
- [ ] ★ 零支付与缺失值的区分；
- [ ] 中央奖励资金是否计入；
- [ ] 省内横向补偿是否剔除；
- [ ] 实际支付、协议金额和预算金额是否区分；
- [ ] 2025 年估算方法。

## 二、配对定义

- [ ] ★ 28 组配对完整编码；
- [ ] ★ 7 个“次级配对”的制度依据；
- [ ] 同一省对出现两次时，两行观测的经济含义；
- [ ] 是否重复使用同一笔资金；
- [ ] 配对开始和终止年份。

## 三、上游机会成本

- [ ] ★ 生态政策处理变量；
- [ ] ★ 处理时点；
- [ ] ★ 处理组与对照组；
- [ ] 工业增加值、FDI、生态红线及控制变量；
- [ ] DID 或其他反事实模型代码；
- [ ] 纵向补助与直接治理成本。

## 四、下游生态收益

- [ ] ★ GTFP 原始投入产出数据；
- [ ] SBM-GML 设置与结果；
- [ ] 水安全价值的价格和数量口径；
- [ ] 高耗水产业口径；
- [ ] 各代理指标向货币收益转换的公式。

## 五、国际标尺校准

- [ ] ★ 81 亿元总额的逐步计算；
- [ ] 58%、22%、20% 权重的原始用水数据；
- [ ] 权重年度是否变化；
- [ ] 财政自给率修正方案；
- [ ] 莱茵河与科罗拉多河规则对应到长江变量的映射表。

## 六、软件与复现

- [ ] Stata 版本和已安装命令；
- [ ] R 版本和包；
- [ ] 原始代码；
- [ ] 数据字典；
- [ ] 预期复现的表格与图形清单。
